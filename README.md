# fitcore-studio
Trabalho de Design Profissional (Engenharia de Software) de Pedro Taddei Viante.

O sistema FitCore Studio foi desenvolvido como uma solução simples para um problema real de organização e acompanhamento de treinos.
A escolha de um sistema web permite centralizar as informações que antes estavam espalhadas entre fichas de papel, PDFs e mensagens.
O protótipo mantém a proposta de atendimento personalizado do Studio FitCore, mas utiliza a tecnologia para facilitar o trabalho dos professores e melhorar a experiência dos alunos.
Mesmo utilizando uma estrutura simples e LocalStorage, o projeto demonstra como uma solução digital pode reduzir processos manuais, organizar os treinos e aumentar a percepção de acompanhamento contínuo.
O projeto também possui possibilidade de expansão para uma aplicação completa, com banco de dados, autenticação, múltiplos usuários e métricas de desempenho e retenção.
